# 120 秒演示脚本（本地路径）

> v1 已部署至 https://invest-agent-quality-lab.opalescentdisco1.chatgpt.site，但 owner-only 且需 ChatGPT 登录；用户登录后的评审访问尚未验证。登录前用本地演示时标出是本地环境。预置案例和行情 eventContext 均为合成材料，只有 iFinD 查询项是实际工具返回的受限历史行情。

- 0–12 秒：说明这是投资回答质检台，20 条样例为合成数据；展示预置 A/B 和确定性规则版本。
- 12–30 秒：运行规则评测，打开一条 2026-10 合成事实案例，说明配置的 evidence claim、单位、期间及缺证据状态。事实准确率/覆盖率仅针对配置 claims。
- 30–48 秒：切换工具页，展示 iFinD 真实返回：300033.SZ、2026-11-06、不复权收盘价、人民币元、202.7 元；输入 210 元，展示 MISMATCH。说明只证明这个限定价格主张，不能外推到其它证券/日期/事实。
- 48–60 秒：展示合成 eventContext 的发生/公开时间。指出它是虚构事件，不是真实新闻；只有答案引用配置短语且公开时间晚于回答生成时间时才标未来信息。
- 60–76 秒：打开短期/高流动性画像与收益保证案例，说明 finding 是风险线索，需人工复核，不是法律意见。
- 76–92 秒：展示反馈处理、人工确认后加入去重回归集和历史运行快照。API 冒烟 15/15 已覆盖这些动作；录制现场 UI 操作时勿显示真实个人信息。
- 92–105 秒：比较候选 A/B，展示分子分母和明确失败/待核验状态；指出客观事实不因画像改变。
- 105–114 秒：展示模型未配置说明；mock 测试不等于 live 模型调用。
- 114–120 秒：列出本地测试记录、v1 登录门与线上 smoke 边界、交付限制。不要声称匿名可访问。

录制前确认模型配置状态、数据来源说明和当前 build。10 张操作截图已保存在 `artifacts/screenshots/01-overview.jpg` 至 `10-mobile.jpg`。最终视频纳入交付 ZIP 后确认总量 ≤30 MB。
