# 已知限制与未完成事项

- 仅有五类确定性检查中的部分 rule IDs 实际执行。意图使用导入案例里的预设值；case-diagnosis 尚不执行，虽有 Skill 规范但不是自动诊断。
- `snapshot-verifier` 使用合成快照，不能代表真实证券价格或真实市场覆盖。当前四条行情意图中的 eventContext 是虚构事件情景，不是真实新闻。FRESHNESS-001 依赖配置的 referencePhrases 命中和时间字段，不是通用新闻事件识别器。
- iFinD 可查询一组受限证券/字段与历史日期，现有真实核验样例仅覆盖 300033.SZ、2026-11-06、不复权收盘价、人民币元。返回值需分别核对证券、日期、复权、单位、来源和更新时间。若返回行内日期明确且匹配目标日，可以据此核验；行日期与显式参数不一致时待核验。若行内没有日期，则参数须明确等于目标日；参数为“最新”或缺失时待核验。单次价格比较不等于整条回答或全部金融事实通过核验。
- iFinD HTTP/MCP 查询与导入案例中的合成事实评测相互独立；用户手动提供一个回答价格时可以做受限比较；不会自动把 iFinD 查询绑定到任意评测 run 的 claim/evidence。
- `timeout-probe` 是模拟异常；不代表真实上游异常。
- 模型 API 未配置。模型评测与生成没有 live 调用；mock 协议、脱敏、证据引用拒绝测试不能代替真实模型验证。
- 个性化、合规和归因检查只提供风险线索；不能替代适当性判断、法律意见或监管结论。
- 自动规则尚未用足量的人工金标准样本校准，不报告普遍准确率或误报率。
- 已有 API smoke 15/15、Node 24 测试 29/29 和类型检查通过记录；API smoke 覆盖反馈处理与确认后加入去重回归集。浏览器 overview 截图已留存，但完整 UI 操作仍需逐步截图。
- Sites 尚未发布，不存在可以交给评审访问的公开网址。部署需相应发布访问权限，并由用户/管理员提供可用的模型配置及是否允许将其用于评测的授权。
- 最终提交 ZIP 是否小于等于 30 MB 仍待打包确认。



- 一次同步评测最多处理 20 条，导入最多 50 条；单会话运行最多 20 次，会话状态限制为 1.5 MB。超出限制会返回错误，需要减少样本或导出后重置。
