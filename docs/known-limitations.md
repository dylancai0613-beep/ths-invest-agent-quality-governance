# 已知边界与未完成事项

- 外部模型服务未配置，语义评测与生成仅验证适配协议、输出结构和脱敏，没有live模型调用。人工修订可以在不依赖模型的情况下完成真实修改、保存和复测。
- 五个Skill有确定性实现；意图来自案例标签，case-diagnosis仅为规范。规则不等于完整语义判断、适当性审核或法律合规认证。
- 所有预置问答、KYC和事件情景为合成。iFinD证据为另行保存的实际工具返回，不能把两者混为真实市场回测。
- 线上iFinD直连观察到HTTP522，本地可实际调用。没有确认根因，也没有把失败伪装成功。历史模式必须主动选择，仅覆盖300033.SZ、2026-11-06、不复权收盘价、人民币元；原始查询时间和本次提供时间分开。
- 事实检查不是通用全量主张抽取，主要围绕配置证据和已识别行情断言。未提取或证据不足不能被解释为事实已经正确。
- 画像不变性有五组确定性配对测试，未验证真实生成模型在所有画像下的行为。用户反馈是检查线索，不是事实真值。
- 会话隔离依赖浏览器HttpOnly Cookie。当前D1采用会话JSON存储，面向单人演示；不支持企业多角色权限、复杂并发审计或跨设备账号同步。
- 同步每次最多20条、导入最多50条、会话最多20次运行和20个版本、状态不超过1.5MB。超出需导出并重置。
- 网站目前仅拥有者可访问，未开放为匿名评审站点。源码在Sites私有Git仓库，交付包另附源码ZIP；评审访问仍需用户决定。
- 视频为117秒操作截图说明，非连续录屏。未自动提交招聘系统。没有独立金融或法律审阅签字。
