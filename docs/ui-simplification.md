# 界面简化与深色主题

按用户确认的需求实施：

- 保留概览；移除首页当前候选版本卡片、事实准确率和证据覆盖率指标。
- 导入问答集、导出结果、开始规则评测集中于评测任务。移除全局反馈按钮和反馈填写弹窗。
- 评测任务页列出当前会话保存的全部测评运行；选中某次运行后查看对应的测评结果。“案例结果”统一称为“测评结果”。
- 移除版本比较导航与专页，底层继续保留历史版本和运行证据。
- 详情顺序为问答、匿名KYC、问题规则、人工修订建议与复测、AI辅助复核、判断依据、人工复核。
- 规则预置回答不再在详情中冒充现场AI回答；需要时按当前问题调用已配置模型生成并自动复测。模型回答突出问题相关性、KYC期限与流动性约束，并避免收益保证或无证据结论。
- 可见实体名称使用基金甲等简洁文案；演示数据属性集中说明，原始数据与历史证据不被展示用名称覆盖。
- 判断依据的示例来源展示www.sample.com，属于示例域名，不作为真实已访问来源。
- 用户行为反馈取代手工意见提交；仅记录实际发生的匿名演示操作，不把工作台使用行为宣称为生产投资用户数据，也不由行为直接判定答案正确。
- 采用近黑、深暖灰背景与克制陶土强调色，保留金融状态颜色；工具与Skills只同步主题和移除重复入口，结构另行讨论。

实现后的操作验证另记于artifacts和测试说明；本文件是需求范围，不能代替执行证据。
